# MOCK dataset (fictional): test oracle

**Everything in this folder is MOCK data.** All creators, handles, brands, news outlets and websites are fictional (websites use the reserved `.example` domain). Display names look like normal Czech names on purpose; every fetched object carries `source.mode = "mock"` and the UI shows a MOCK badge. Any resemblance to a real account is coincidental.

Generated by `fixtures/generate.py` (deterministic, seeded). **Do not edit the JSON or this README by hand.** Regenerate from the repo root:

```
backend/.venv/bin/python fixtures/generate.py          # writes fixtures/*.json + README.md
backend/.venv/bin/python fixtures/generate.py --check  # fails if the files on disk are stale
```

Before writing, the generator runs a *reference funnel* (own simple metric code + lingua, rules from docs/architecture.md section 5, criteria from `briefs.json`) and aborts if any candidate's outcome differs from the design or a decisive value sits within 10 % of its threshold. Everything below comes from that run.

## Files

| File | Shape |
|---|---|
| `meta.json` | `{anchor, seed, ...}`. All timestamps are relative to `anchor`; MockProvider shifts them by `now - anchor` |
| `discovery.json` | `[CandidateRef]`, one per (creator, path): 67 raw refs, 49 unique, the minor is dropped by the provider -> **48 candidates** |
| `profiles.json` | `[Profile]` with `latest_posts` (12-24 posts, private accounts have none) |
| `posts.json` | `{"<platform>:<handle>": [Post]}` older posts (up to ~5 months) for the 9 finalists; `posts()` returns latest + these |
| `comments.json` | `{post_url: [Comment]}` for the newest 7 posts of every public creator, max 15 per post, text only (no commenter identity) |
| `collabs.json` | `{"<platform>:<handle>": [CollabEvidence]}` Meta Branded Content records (kind `meta_branded`) |
| `news.json` | `[NewsItem]`; `news(query)` matches query tokens against title + snippet |
| `cross_platform.json` | `{"<platform>:<handle>": [Profile]}` for `find_cross_platform` |
| `briefs.json` | `{"bakery": CriteriaSet, "fitness": CriteriaSet}` canonical demo criteria (params = app/presets.py, plus 2 competitors and refused examples per goal) |
| `expected.json` | machine-readable version of this README (oracle for tests) + `post_topics` {post_id: designed topic} |

## Notes for implementers

- **Dates**: fixtures are written relative to `meta.json.anchor`; MockProvider shifts every timestamp by `now - anchor` at load. Active creators posted 0.4-3 days before now; inactive ones 104-131 days.
- **Discovery**: `discover(DEMO_DISCOVERY)` returns one ref per path (search, hashtag, place, related); round 0 must dedupe by (platform, handle) and merge `found_via`. A query matching nothing returns the whole pool.
- **Brand accounts**: `is_business=true` with `business_category` in `Bakery`, `Café`, `Gym/Physical Fitness Center`, `Brand`, `Restaurant`. Creator business accounts use `Digital creator`, `Blogger`. TikTok profiles have `is_business=None` (unknown).
- **Paid labels**: unlike real Instagram data (often `None`), the mock sets `paid_partnership` to `true`/`false` on every post, so `disclosed=False` is reachable for unlabeled brand posts.
- **Topics**: every post carries 2+ topic hashtags (see `expected.json.topic_hashtags`) and topic words; `expected.json.post_topics` has the designed topic per post for testing `topics.fallback_classify`.
- **Local signal**: local creators have `Brno` in bio, `#brno...` hashtags and `location_name` like `Brno - Zelný trh` on every third IG post. Prague/Ostrava creators have no `brno`/`brněnsk` anywhere.
- **Comments**: categories per creator are stratified per post (Czech, Slovak, English, emoji-only, generic). Generic phrases: `expected.json.generic_comment_phrases`.
- **Engagement spikes**: `srdicka_a_dorty` and `fit_mama_eliska` have two posts with ~5x interactions.
